# 🎮 RPG Quest Todo (갓생 모험가 투두리스트)

> **"일상을 모험처럼!"**  
> 16비트 레트로 픽셀 아트 RPG 게이미피케이션 요소와 일일 태스크 관리, 주간 출석 체크 시스템이 결합된 싱글 페이지 웹서비스입니다.  
> 기획서(`프롬포트.md`)의 모든 요구사항과 스티치 디자인 시스템(Dark RPG UI)을 100% 충실히 구현하였습니다.

## 🌟 주요 기능 요약

### 1. ⚔️ 4대 직업 전체 7대 계층(총 20단계) 점진적 칭호 & 고유 16비트 진화 디자인
단순한 색상 필터(색칠놀이)가 아니라, `pixel_sprites.js`의 **64×64 16비트 도트 드로잉 엔진**을 통해 **모든 4개 직업(`전사`, `궁수`, `마법사`, `비스트`)**이 칭호 변화(`초급 ➔ 중급 ➔ 고급` 및 `강림 ➔ 불멸 ➔ 태초 ➔ 창세/절대`)에 맞춰 **무기·갑옷·투구·날개·오라·종족 실루엣**이 점점 더 멋있고 웅장하게 진화합니다. 동시에 각 직업만의 고유한 아이덴티티(상징 무기와 실루엣)를 유지하여 어느 단계에서든 같은 직업 계보임을 한눈에 알아볼 수 있습니다.

### 2. 🪞 외형 진화 비교창 (Evolution Comparison Modal - Before vs After)
- 5레벨마다 진화에 도달하거나, 메인 대시보드의 `[ 🔍 진화 비교 ]` 버튼 또는 칭호 도감의 `[ 👁️ 외형 비교 ]` 버튼 클릭 시 팝업:
  - **상단 직업/단계 전환 바:** 전사·궁수·마법사·비스트 4개 직업을 즉시 전환하거나 `◀ 이전 단계` / `다음 단계 ▶` 버튼으로 20단계 전체 진화 과정을 실시간 비교 가능
  - **좌측 [ 이전 모습 (BEFORE) ] vs 우측 [ 진화한 모습 (AFTER) ]:** 직전 단계와 각성 단계의 16비트 픽셀 외형, 칭호, 설명, 각성 특성을 나란히 비교
  - 승리의 에볼루션 전용 아르페지오 팡파레 & 화면 전체 폭죽 세레머니!

### 3. 👑 캐릭터 신체에 직접 착용되는 정밀 16비트 악세서리
- 주변에 둥둥 떠있지 않고 각 직업·진화 단계별 신체 픽셀 좌표(`headX/Y`, `eyeX/Y`, `neckX/Y`, `backX/Y`, `handX/Y`)에 맞춰 직접 착용되는 구조:
  - 👑 **황금 왕관:** 머리/이마 위에 꼭 맞게 도트로 착용
  - 🪽 **천사 날개:** 등 뒤/어깨죽지에서 자연스럽게 돋아나 펼쳐짐
  - 💫 **마법 후광:** 머리 바로 위에서 신성하게 발광
  - 🕶️ **픽셀 선글라스:** 캐릭터의 실제 두 눈 위치에 정밀 안착
  - 🧿 **황금 행운 목걸이:** 목에 황금 체인이 걸리고 가슴 중앙에 에메랄드 펜던트가 안착
  - 🐱 **분홍 고양이 귀:** 머리 위에 헤어밴드 형태로 착용
  - 🧣 **영웅의 붉은 망토:** 어깨에 황금 브로치로 고정되어 등 뒤로 나부낌
  - ⚔️ **황금 엑스칼리버:** 캐릭터의 손에 직접 쥐어져 성광을 발산

### 4. ⚔️ 직업 선택 제단 & 클린 스타트 (Lv.1, 0 EXP, 0개 퀘스트)
- 첫 접속 시 4종 16비트 캐릭터의 **3단계 진화 미리보기(`Lv.1 초급 ➔ Lv.45 중기 ➔ Lv.100 신화`)**를 확인하며 직업을 선택하고 모험가 이름을 등록하는 모달이 최우선으로 팝업됩니다.

## 🚀 실행 및 배포 방법 (GitHub & Vercel)

### 1. GitHub 업로드 & Vercel 원클릭 배포
본 프로젝트는 `vercel.json`, `.vercelignore`, `.gitignore`, `package.json` 설정이 모두 완료된 **정적 웹 애플리케이션(Static Web App)**으로, 별도의 빌드 과정 없이 GitHub 저장소 연결만으로 즉시 배포됩니다.

```bash
git init
git add .
git commit -m "feat: RPG Quest Todo 16-bit web service"
git branch -M main
git remote add origin https://github.com/<내-깃허브-아이디>/<저장소-이름>.git
git push -u origin main
```

1. [Vercel 대시보드](https://vercel.com/new)에 접속하여 **Add New... ➔ Project** 클릭
2. 방금 푸시한 GitHub 저장소를 **Import**
3. **Framework Preset**은 `Other` (기본값) 그대로 두고 **Deploy** 버튼 클릭 (루트의 `vercel.json`이 자동으로 인식되어 즉시 배포 완료!)

### 2. 로컬에서 실행하기
- **브라우저 직접 실행:** `index.html` 파일을 더블 클릭하여 바로 열기
- **로컬 서버 실행:**
  ```bash
  python server.py
  # 또는
  npx serve .
  ```
